# 🌐 Registro de Horas Voluntáriado — ABCAA

Site oficial para registro de horas voluntáriados da Associação Beneficente e Cultural Amor em Ação.

## 📋 Sobre o projeto
Modelo simples de registro de horas e relatório de atividades do voluntariado.

## 🛠️ Stack
> Preencher com a tecnologia utilizada (ex: React, Next.js, HTML/CSS puro...)

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/abcaa-ong/volunteer-hours-log.git

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```

## 📁 Estrutura de pastas

```
site-institucional/
├── public/          → Arquivos estáticos
```
